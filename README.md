## EN

**Magic Cat AIGC Studio** is an independent studio working at the intersection of AI filmmaking and agent systems. We turn hard-won production experience — directing workflows, prompt craft, multi-agent collaboration — into open, reusable tools and skills.

### What we're building

- 🎬 **AI Filmmaking** — AI short dramas & animated series, from script to screen
- 🎥 **Director Workflows** — a full directing pipeline (script breakdown → shot design → prompt packages) packaged as agent skills
- 🤖 **Multi-Agent Systems** — agent teams that research, produce and review together
- 📦 **Open Source** — production-grade skills and checklists, released as they mature

### From our open-source library

Tools and references we actively study, evaluate and build on:

- **Toonflow-app** — open-source AI short-drama production platform; our reference study for studio-grade asset & storyboard management
- **Hallmark** — anti-AI-slop design audit skill; our design QA standard for web work
- **Hyperframes** — HTML-to-video rendering; our pipeline for programmatic explainer videos
- **Higgsfield CLI / SDKs** — official Higgsfield tooling; reference for our agent integration layer

### Coming soon

Our own skills, distilled from real productions — starting with a **short-drama release checklist** (platform rules, rights paperwork, review pitfalls) and a **cinematic prompt-craft skill** for AI video generation.

## 中文

**魔力喵 AIGC 工作室**是一家专注于 AI 影视与 Agent 系统的工作室。我们把一线制作经验——导演工作流、提示词工艺、多 Agent 协作——沉淀成开放、可复用的工具与 skill，陆续在这里发布。

### 我们在做的事

- 🎬 **AI 影视** — AI 短剧 / 漫剧全流程制作，从剧本到成片
- 🎥 **导演工作流** — 从剧本拆解、分镜设计到提示词包的完整导演管线，封装为 Agent skill
- 🤖 **多 Agent 协作** — 能调研、能生产、能互相审核的 Agent 团队系统
- 📦 **开源发布** — 在真实项目里打磨成熟的 skill 与检查清单，成熟一个、发布一个

### 正式库亮点（在学、在用的开源项目）

- **Toonflow-app** — 开源 AI 短剧制作平台，我们做 Studio 级资产与分镜管理的对照研究对象
- **Hallmark** — 「反 AI 味」设计审计 skill，我们网站工作的设计质检标准
- **Hyperframes** — HTML 渲染视频，我们程序化讲解视频的管线
- **Higgsfield CLI / SDK** — Higgsfield 官方工具链，我们 Agent 调用层的集成参照

### 即将发布

工作室自研 skill，第一批：**短剧上线检查清单**（平台规则 / 权属材料 / 审核避坑）与**影视级提示词工艺 skill**（AI 视频生成）。
